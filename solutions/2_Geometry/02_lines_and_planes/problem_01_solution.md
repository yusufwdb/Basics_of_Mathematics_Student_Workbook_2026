# Exercise 1: Line Through Two Points

## 1. Problem Statement

Find the equation of the line through $A=(1,2)$ and $B=(4,-1)$ in parametric and general form. Identify a direction vector and an example of a normal vector. Check that both points satisfy the equation you obtain.

## 2. Theoretical Background and Concepts

1. **Direction Vector of a Line Through Two Points:**
   Given two distinct points $A = (x_A, y_A)$ and $B = (x_B, y_B)$ in $\mathbb{R}^2$, the displacement vector
   $$v = \overrightarrow{AB} = B - A = (x_B - x_A,\, y_B - y_A)$$
   lies along the line and serves as a **direction vector** (as does any non-zero scalar multiple $\lambda v$).

2. **Parametric Form of a Line in $\mathbb{R}^2$:**
   Using a known point $A = (x_A, y_A)$ on the line and a direction vector $v = (v_1, v_2)$, every point $(x, y)$ on the line is described by:
   $$(x, y) = A + tv = (x_A + t v_1,\, y_A + t v_2), \qquad t \in \mathbb{R}$$

3. **Normal Vector and General Form of a Line in $\mathbb{R}^2$:**
   A **normal vector** $n = (a, b) \neq (0, 0)$ to a line in $\mathbb{R}^2$ is any non-zero vector perpendicular to its direction vector $v = (v_1, v_2)$, i.e., $n \cdot v = 0$. Rotating $v = (v_1, v_2)$ by $90^\circ$ gives $n = (-v_2, v_1)$ or $n = (v_2, -v_1)$.
   With normal vector $n = (a, b)$ and point $A = (x_A, y_A)$, the **general (implicit) form** of the line is:
   $$n \cdot \big((x, y) - A\big) = 0 \iff a(x - x_A) + b(y - y_A) = 0 \iff ax + by + c = 0$$

## 3. Detailed Step-by-Step Solution

Given points:
$$A = (1, 2), \qquad B = (4, -1)$$

### Step 1: Identify a direction vector
Compute the displacement vector $\overrightarrow{AB}$:
$$v = \overrightarrow{AB} = B - A = (4 - 1,\, -1 - 2) = (3, -3)$$
We can also divide by $3$ to get a simpler collinear direction vector:
$$v' = \frac{1}{3}v = (1, -1)$$
Both $v = (3, -3)$ and $v' = (1, -1)$ are valid direction vectors for the line.

### Step 2: Write the parametric form of the line
Using the initial point $A = (1, 2)$ and the direction vector $v = (3, -3)$:
$$(x, y) = (1, 2) + t(3, -3), \qquad t \in \mathbb{R}$$
or in component form:
$$\begin{cases} x = 1 + 3t \\ y = 2 - 3t \end{cases} \quad (t \in \mathbb{R})$$
(Equivalently, using $v' = (1, -1)$, we can write $(x, y) = (1, 2) + s(1, -1)$ for $s \in \mathbb{R}$.)

### Step 3: Identify a normal vector and find the general form
Since the direction vector is $v' = (1, -1)$, a vector $n = (a, b)$ perpendicular to $v'$ must satisfy $n \cdot v' = a(1) + b(-1) = 0 \implies a = b$. Choosing $a = 1, b = 1$ gives the normal vector:
$$n = (1, 1)$$
(check: $n \cdot v = (1)(3) + (1)(-3) = 0$).

Using $n = (1, 1)$ and the point $A = (1, 2)$, the point-normal equation of the line is:
$$1(x - 1) + 1(y - 2) = 0$$
Expanding and collecting terms gives the **general form**:
$$x + y - 3 = 0 \quad (\text{or } x + y = 3)$$

## 4. Verification and Consistency Checks

1. **Check that $A = (1, 2)$ and $B = (4, -1)$ satisfy the general equation $x + y - 3 = 0$:**
   - For $A = (1, 2)$: $1 + 2 - 3 = 3 - 3 = 0 \quad \checkmark$
   - For $B = (4, -1)$: $4 + (-1) - 3 = 3 - 3 = 0 \quad \checkmark$

2. **Check that $A$ and $B$ are generated by the parametric equation $(x, y) = (1 + 3t,\, 2 - 3t)$:**
   - Setting $t = 0$: $(x, y) = (1 + 0,\, 2 - 0) = (1, 2) = A \quad \checkmark$
   - Setting $t = 1$: $(x, y) = (1 + 3,\, 2 - 3) = (4, -1) = B \quad \checkmark$

3. **Check that every parametric point satisfies the general form:**
   Substituting $x = 1 + 3t$ and $y = 2 - 3t$ into $x + y - 3$:
   $$(1 + 3t) + (2 - 3t) - 3 = 3 + 0t - 3 = 0 \quad \forall t \in \mathbb{R} \quad \checkmark$$
